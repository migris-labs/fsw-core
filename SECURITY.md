# Security Policy

## Reporting a vulnerability

If you believe you have discovered a security-relevant issue in
`migris-labs/fsw-core`, please report it privately.

- Email: **max.giacalone@icloud.com**
- Please include: a description of the issue, steps to reproduce, an
  assessment of the potential impact, and any suggested remediation.

We aim to acknowledge reports within 72 hours and to provide a remediation
timeline within two weeks. Please do **not** open a public GitHub issue
for security reports.

## Supported versions

This project is pre-1.0 and under active development. Only the latest
tagged release (and `main`) is supported. We do not backport fixes to
earlier pre-1.0 releases.

## Scope

This policy covers the source code and build artefacts in this repository.
It does not cover third-party dependencies; please report those upstream.
